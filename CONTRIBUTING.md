# Contributing

Thank you for helping make owner-controlled software easier to use.

1. Open an issue describing the problem or proposed change.
2. Keep changes within the Lite boundary: local Focus, local state, local receipts, and read-only update discovery.
3. Add or update tests and run `npm test` plus `npm run release:check`.
4. Submit a focused pull request and explain any authority or privacy implications.

Features that connect accounts, perform external actions, or add hosted services belong in the commercial Mission product rather than this repository.
